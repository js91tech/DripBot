WHAT THE AUTO ROUTER DOES:
──────────────────────────
Instead of hardcoding one model, set model to "openrouter/auto" and
OpenRouter's AI analyzes each prompt and picks the best model:
  - Simple questions → cheaper/faster model
  - Complex reasoning → powerful model (Claude, GPT, etc.)
  - No extra cost — you pay standard rates for whichever model is picked

Dashboard has a toggle on the Models tab. When ON:
  - Model selection grid dims out (auto handles it)
  - You can filter which providers are allowed (Anthropic, OpenAI, etc.)
  - Badge shows "AUTO ROUTER" in the header

When OFF:
  - Manual model selection works like before
  - Click any model card to set it


TROUBLESHOOTING:
────────────────
Q: "Sidecar crashed on start" in logs
A: Make sure zai_sidecar.py is in your project root (same folder as bot.py)

Q: Avatar upload returns "Discord rejected avatar"
A: Bot tokens can't change avatars on bot accounts via the API.
   You need to change it at https://discord.com/developers/applications

Q: Personality presets don't load
A: Check Render logs for 500 errors on /api/personality.
   Make sure your settings_manager is initialized before the API starts.

Q: Auto Router toggle doesn't save
A: Make sure "auto_router_enabled" is in your default_settings.py
