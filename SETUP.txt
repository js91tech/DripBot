DRIPSLETONGUE SETUP
===================

This repository now contains the integrated Python bot, FastAPI dashboard, and
Python Z.ai sidecar. There are no separate patch files to copy into place.

Required environment variables:
- DISCORD_TOKEN: Discord bot token.
- OPENROUTER_API_KEY: Required for LLM responses and OpenRouter image models.
- ZAI_API_KEY: Required only for Z.ai sidecar vision/search/image generation.

Optional environment variables:
- BOT_PREFIX: Prefix command marker, defaults to !.
- DASHBOARD_PORT: Dashboard/API port, defaults to 8080.
- ZAI_SIDECAR_PORT: Local sidecar port, defaults to 3456.
- KEEP_ALIVE_URL: URL used by the built-in keep-alive ping loop.

Local setup:
1. Install dependencies:
   pip install -r requirements.txt
2. Export the required environment variables.
3. Start the bot:
   python3 bot.py

Render setup:
- Build command: pip install -r requirements.txt
- Start command: python bot.py
- The Python sidecar starts automatically from bot.py when zai_sidecar.py is
  present.

Auto Router:
- Manual model selection is used when auto_router_enabled is false.
- When auto_router_enabled is true, OpenRouter receives openrouter/auto and the
  optional auto_router_allowed_models list from settings.

Trainer:
- To seed Markov data, set the target guild explicitly:
  GUILD_ID=123456789012345678 python3 trainer.py
  or
  python3 trainer.py 123456789012345678
